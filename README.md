# Anchor

A little space before the next step.

Anchor is an app I'm building for people living with borderline personality disorder (BPD), and anyone who finds it useful to pause, ground themselves, or have a plan ready when things get difficult.

It's still in development. Android comes first, with iOS planned later.

## What's working

- **Pause before replying** — take a moment away from a conversation and write a draft without sending it.
- **Grounding** — a guided five-senses exercise, at your own pace.
- **Support plans** — six editable starter plans, or create your own with links, apps and support contacts.
- **Journal** — free writing, optional check-ins, search and past entries.
- **Backups** — file import/export and optional account-based cloud backups for plans and journal entries.

The core tools work offline and don't require an account. Cloud backups need an internet connection.

## Where it's heading

The next priorities are refining Grounding and Pause, adding an urgent-help screen with verified support resources, and giving the app a proper visual pass. English, German and French localization is also planned.

## Built with

Kotlin, Compose Multiplatform, Android DataStore and Supabase.

---

Anchor is a personal support tool, not a replacement for therapy or emergency services. The starter-plan content is still being reviewed.
